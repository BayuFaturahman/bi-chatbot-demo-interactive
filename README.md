# BI Chatbot Demo Interactive

## Jalankan di local

```bash
npm install
npm run dev
```

Buka:
http://localhost:5173

## Yang sudah diperbaiki
- input sekarang bisa diketik
- tombol kirim bisa diklik
- contoh pertanyaan bisa diklik
- chart dan KPI berubah sesuai pertanyaan:
  - penjualan
  - cabang
  - produk
